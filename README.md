# 🧺 Laundry Wallah / Laundry Mart

A simple and beginner-friendly **Laundry Service Website** built using **HTML5**.
The website provides information about laundry services, pricing, and a basic booking form for customers.

## 📌 Project Overview

**Laundry Wallah / Laundry Mart** is a static laundry service webpage designed to demonstrate the use of basic HTML concepts such as:

* HTML structure
* Headings and paragraphs
* Images
* Lists
* Tables
* Forms
* Input fields
* Sections
* Header and footer

The project is suitable for beginners who are learning **HTML and Web Development**.

---

## ✨ Features

### 🏠 About Us

Provides a brief introduction to Laundry Wallah / Laundry Mart and explains the services offered by the business.

### 🖼️ Laundry Image

Includes a laundry-related image to make the webpage more visually appealing.

### 🧺 Our Services

The website displays a list of available services:

* Washing
* Drying
* Ironing
* Folding
* Dry Cleaning
* Stain Removal
* Express Service
* Special Garment Care
* And Many More

### 💰 Price List

A simple pricing table is provided for some of the major services.

| Service       |  Price |
| ------------- | -----: |
| Washing       | ₹10.00 |
| Ironing       |  ₹5.00 |
| Dry Cleaning  | ₹20.00 |
| Stain Removal | ₹10.00 |

### 📅 Book Now

A basic customer booking section is included where users can enter:

* Name
* Email
* Phone Number

### 📞 Contact

The website provides an email address for contacting the laundry service.

## 🚀 How to Run the Project

```bash

```

Go to the project folder:

```bash

```

Open the `index.html` file in any modern web browser.
